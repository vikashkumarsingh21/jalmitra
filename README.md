# 🌊 Jalmitra - Smart AI-Based Solar Water Cleaning Boat

Jalmitra is an innovative smart water cleaning system designed to protect rivers, lakes, ponds, and other water bodies using Artificial Intelligence and renewable solar energy. The project combines a modern responsive web platform with a backend inquiry management system to showcase real-time monitoring, environmental awareness, and autonomous water cleaning technology.

This project demonstrates how AI, IoT, and sustainable engineering can work together to solve real-world environmental problems.

---

# 🚀 Project Overview

The Jalmitra platform provides:

* A modern responsive website for showcasing the project
* AI-powered water cleaning solution presentation
* Live monitoring dashboard interface
* Inquiry/contact management system
* Backend API integration with MongoDB

---

## 2️⃣ Navigate to Project Folder

```bash

```

---

# 🌐 Frontend Setup

Simply open the frontend files in your browser.

```bash
fronted/index.html
```

You can also use VS Code Live Server for better development experience.

---

# ⚡ Backend Setup

## Install Dependencies

```bash
cd backend
npm install
```

---

## Create Environment File

Create a `.env` file inside the backend folder.

```env
PORT=3000
MONGODB_URI=your_mongodb_connection_string
```

---

## Run Backend Server

```bash
npm start
```

For development mode:

```bash
npm run dev
```
